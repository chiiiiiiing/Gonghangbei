# AlphaLens 可演示成果

本报告仅供研究参考，不构成投资建议

这里是比赛演示的统一入口。第一次使用请直接阅读 [`完整说明文档.md`](完整说明文档.md)。

## 快速启动

在仓库根目录执行：

```bash
.venv/bin/python 可演示成果/启动演示.py
```

浏览器打开 `http://127.0.0.1:8701`。

## 文件

| 文件 | 用途 |
|------|------|
| `完整说明文档.md` | 架构、技术路线、操作、演示话术、测试、限制和交接说明 |
| `启动演示.py` | 从统一入口启动 Flask Demo |
| `配置示例.env` | 可选的服务端固定模型配置示例，不包含密钥 |
| `测试案例.csv` | 5 条新输入文本测试案例 |
| `截图/` | 桌面端、移动端、历史研究和严格 AI 模式验收截图 |

运行代码和正式数据只有一份，分别位于仓库根目录的 `app/`、`src/` 和 `data/sample/`；本文件夹不复制源码或 CSV，避免演示版本与研究版本分叉。
