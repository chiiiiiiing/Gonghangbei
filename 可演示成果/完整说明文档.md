# AlphaLens 可演示成果完整说明

更新日期：2026-08-02

本报告仅供研究参考，不构成投资建议

## 一、成果定位

AlphaLens 是面向金融文本研究的量化研究助手。它把政策、公司公告、财经新闻和互动问答等非结构化文本转化为可解释、可回测、可复用的另类因子研究素材。

系统不预测股票价格，不输出买卖建议，也不把大模型生成内容直接当成投资结论。大模型负责提出结构化研究候选，程序负责字段约束、证据校验、冻结规则匹配、因子计算和历史回测审计。

## 三、系统架构

```text
浏览器单页界面 app/index.html
        ↓ HTTP
Flask API app/server.py
        ├── 新文本分析 src/pipeline/live_analysis.py
        │       ├── 本地 Embedding src/ai/research_layer.py
        │       ├── DeepSeek JSON src/ai/gateway.py + prompts.py
        │       ├── 实体、事件、谓词程序校验
        │       └── 冻结规则匹配与候选因子
        └── 历史研究 data/sample/*.csv
                ├── 规则库与历史因子截面
                ├── 分组收益与 Rank IC
                └── 未来函数审计
```

页面有两个工作区：

1. **新文本分析**：输入一篇有来源、日期和正文链接的文本，生成当下可解释的候选因子。
2. **历史研究概览**：读取固定历史样本生成的规则、因子、回测指标和审计结果。

新文本不会写回历史 CSV，也不会临时获得尚未发生的未来收益。历史回测与新文本即时分析在时间上严格分开。

## 四、模式一的强制技术路线

`模式一：大模型候选 + 规则校验` 固定执行：

```text
新文本
→ Embedding 检索相似冻结规则
→ DeepSeek V4 Flash 返回结构化 JSON
→ 程序校验股票、事件、证据和谓词
→ 确定性谓词与 AI 判断对照
→ 冻结规则匹配
→ 候选因子
```

### 1. Embedding 检索

默认使用 `local-char-ngram-embedding-v1`：

- 把新文本和冻结规则文本映射为 512 维字符 n-gram 向量。
- 使用稳定哈希保证同一输入跨进程得到相同向量。
- 使用余弦相似度返回最接近的 5 条冻结规则。
- 检索结果进入大模型 Prompt，帮助模型理解当前规则库。

它是轻量、可复现的词法 Embedding，不等同于 BGE 等专用中文语义向量模型。DeepSeek 当前公开 API 没有本项目直接使用的 Embeddings 端点，因此没有把不存在的接口包装成官方能力。

### 2. DeepSeek 结构化 JSON

- Base URL：`https://api.deepseek.com`
- 模型：`deepseek-v4-flash`
- 接口：OpenAI 兼容 Chat Completions
- 输出：JSON Object
- 思考模式：关闭，以降低演示延迟并保持 JSON 输出稳定
- Prompt 版本：`alphalens-research-v1.0`

模型返回事件、相关股票、19 个谓词和候选规则。候选规则状态固定为“待统计验证”，不能直接写入正式规则库。

### 3. 程序校验

程序检查：

- 股票代码必须属于 30 只股票池。
- 事件类型必须属于锁定枚举。
- 证据文本必须能在输入正文中找到。
- 谓词名和值必须符合 Schema。
- 置信度与数值字段必须在合法范围。
- 非法股票、重复项和无原文证据候选会被丢弃并记录。

### 4. AI 与确定性结果对照

程序同时按冻结逻辑生成谓词，再逐项对照 AI 判断。页面显示一致数量；不一致项用于审计，不直接覆盖确定性结果。

### 5. 冻结规则与候选因子

只有 `status=qualified` 且历史支持数不少于 5 的冻结规则参与匹配。候选因子公式为：

```text
候选因子
= 触发规则评分和
× (0.7 × 事件证据强度 + 0.3 × 事件短期影响先验)
```

页面会显示每只关联股票的实体证据、事件、19 个谓词、规则条件、支持数、历史胜率和公式拆解。

### 6. 模式一失败策略

模式一没有静默回退：

- 未填写 Key：页面立即报错。
- Key 无效、额度不足或接口不可达：后端返回 HTTP 503。
- 大模型返回非法 JSON：直接报错。
- AI 结果未通过必要结构校验：直接报错。
- Embedding 未执行：直接报错。

失败响应不会包含候选因子或 `stock_results`，避免把纯规则结果冒充 AI 结果。

## 五、模式二的边界

`模式二：仅规则复现` 不调用大模型，用于：

- 断网环境检查页面和历史研究结果。
- 复现实体、事件、谓词、冻结规则和公式。
- 定位模型之外的程序问题。

页面会明确显示“模式二：仅规则复现”。演示和答辩不能把模式二输出描述成 AI 生成结果。

## 七、页面使用步骤

### 模式一

1. 打开“新文本分析”。
2. 选择内置“储能政策”，或填写标题、正文、来源类型、来源名称、首次公开日期和正文链接。
3. 分析引擎选择“模式一：大模型候选 + 规则校验”。
4. 在密码框填写 DeepSeek API Key。
5. 点击“开始分析”。
6. 检查结果页是否依次出现 Embedding、AI JSON、程序校验、AI/规则对照、冻结规则和候选因子。
7. 检查模型为 `deepseek-v4-flash`、Embedding 为 `local-char-ngram-embedding-v1`。
8. 检查 Key 输入框已经自动清空。

### 模式二

1. 分析引擎选择“模式二：仅规则复现”。
2. 不填写 Key。
3. 点击“开始分析”。
4. 检查页面明确标记本次未调用大模型。

## 八、建议演示顺序

### 开场

建议话术：

> AlphaLens 不是用 AI 预测股价，而是让 AI 帮研究员把金融文本转化为可解释、可回测、可复用的另类因子研究素材。

### 现场操作

1. 先打开“历史研究概览”，说明页面直接读取正式流水线 CSV。
2. 展示 30 只股票、130 条文本、210 个事件、12 条合格规则和 167 条历史因子样本。
3. 回到“新文本分析”，点击“储能政策”。
4. 填写 Key 并运行模式一。
5. 指出 Embedding 模型、5 条相似冻结规则和 `deepseek-v4-flash`。
6. 指出 19 个谓词校验和 AI/规则一致数量。
7. 展示候选规则的“待统计验证”状态。
8. 切换关联实体，展示事件证据、谓词和冻结规则路径。
9. 展示候选因子公式，强调它不是买卖信号。
10. 返回历史研究，说明历史回测不是刚输入文本的单次回测。

### 收尾

建议话术：

> 这个 Demo 证明了从非结构化金融文本到结构化因子研究信号的完整链路。当前结果用于研究流程验证，不构成投资建议。

## 九、API Key 安全

- Key 只随当前 `/api/analyze` 请求发送到本地 Flask 后端。
- 后端为本次请求创建 DeepSeek 客户端，不写入文件、CSV、环境变量或日志。
- 响应后密码框自动清空。
- API 响应包含 `Cache-Control: no-store`。
- 页面不使用 `localStorage`、Cookie 或 URL 参数保存 Key。
- Key 不得写进 Git、PPT、截图、录屏或聊天记录。
- 远程部署必须使用 HTTPS；HTTP 仅用于本机 `127.0.0.1`。

仓库没有真实 Key，也没有执行真实账户计费测试。自动测试使用本地模拟 DeepSeek 服务验证请求格式和失败策略。

## 十二、常见问题

| 现象 | 处理方式 |
|------|----------|
| 模式一提示必须填写 Key | 在左侧密码框填写 DeepSeek Key |
| 返回 HTTP 401/403 | 检查 Key、模型权限和账户额度 |
| 返回 HTTP 503 | AI 调用或必要校验失败；查看页面错误，不会生成候选因子 |
| 模式一没有结果但模式二有 | AI 链路失败，不能用模式二结果冒充模式一 |
| 页面打不开 | 确认 Flask 正在 `127.0.0.1:8701` 运行 |
| 端口占用 | 设置 `ALPHALENS_DEMO_PORT` 后重新启动 |
| 图表空白 | 检查 `app/vendor/plotly.min.js` 是否存在 |
| Key 输入后消失 | 这是预期安全行为，每次分析都需重新填写 |

## 十五、已知限制

- 行情使用东方财富 `fqt=1` 前复权价格候选版。
- `adj_factor=1` 是字段占位，不是真实复权因子序列。
- 当前样本、规则和股票池规模有限，统计结果只用于研究链路验证。
- 当前回测未完整计入交易成本、流动性和做空约束。
- 本地字符 n-gram Embedding 主要反映词法相似度，不是专用语义向量模型。
- AI 候选规则仍需历史统计和人工金融口径审核。
- 真实 DeepSeek 账号权限、费用、网络和模型质量仍需团队现场确认。
