# Discovery 互动问答人工核验模板

`Discovery互动问答采集模板.csv` 是空白、锁定字段的人工核验清单；它不是样例数据，不能据此推断任何公司事实或研究结论。

流程：

1. 先运行 `采集Discovery互动问答候选.py`，候选和拒绝报告只会写入被忽略的 `data/external/文本导入暂存/`。
2. 人工逐条打开官方详情页，确认股票、日期、问题与公司回复均与原文一致，并把通过项填入本模板。保留来源 URL，不得复制同一问答或使用 OOS 文本填充 Discovery。
3. 先只暂存校验：

   ```bash
   .venv/bin/python 导入真实文本.py 采集模板/Discovery互动问答采集模板.csv
   ```

4. 仅在人工复核和暂存报告均通过后，才可显式追加 `--apply`。该操作会改变 `data/sample/raw_documents.csv`，因此不能作为演示或日常重算步骤。

字段约束：股票代码只能为六位纯数字；日期为 `YYYY-MM-DD`；`url` 必须是官方详情页。单条问答不代表投资者提问压力，只有确定性流程中的 7 日时间窗聚合才可能形成该事件。

**本报告仅供研究参考，不构成投资建议**
