# 文本与规则增强修正说明

## 修正目标

上一版把大量日常“开展逆回购”公告直接解释成流动性边际增加，并在聚合时用同一个衰减权重同时除以分子和分母，导致单事件在五日窗口内实际上不衰减。规则压力又作为与六类文本因子高度共线的一列进入同一个模型，难以形成独立、可解释的影响。

## 当前实现

1. 日常操作公告只有出现“投放、净投放、加量、超额续作、增加、充裕”等方向证据时，确定性规则才激活“流动性增加”。
2. LLM可以补充词典未覆盖的表达，但必须属于固定14个谓词、置信度不低于0.80，且证据逐字存在于原文。
3. 独立事件按2个交易日半衰期衰减，多个事件先做带符号加总，再经`tanh`限制在[-1,1]，衰减不再被平均抵消。
4. 融合概率固定为90%市场基线加10%文本/结构化模型，限制稀疏文本在制度变化时期的过拟合风险。
5. 冻结规则不再作为重复的拟合特征，而以0.15固定logit权重对上行/下行概率施加方向先验。
6. API和“因子预测”页面分别展示市场基线、文本叠加后、规则调整后三组概率；回测API单列文本和规则的实际改变量。

增强版本为`rates-enhancement-v1.0-20260907`。

## 当前可复现结果

2025年至最新的回顾性时间留出包含82个非重叠五日窗口：

| 路线 | Accuracy | Macro-F1 |
| --- | ---: | ---: |
| 市场基线 | 57.32% | 0.3938 |
| 市场基线+文本叠加 | 58.54% | 0.3998 |
| 市场基线+文本叠加+规则先验 | 59.76% | 0.4275 |

文本叠加相对市场基线提高1.22个百分点准确率和0.0060 Macro-F1。规则先验在32个生效观测中平均改变概率2.18个百分点，改变1次最终分类；最终路线相对市场基线提高2.44个百分点准确率和0.0337 Macro-F1。

20个交易日移动区块Bootstrap的最终准确率差95%区间为`[0.00%, 6.10%]`。因此可以说“规则和文本已经对预测产生可测量影响，并出现正向点估计”，不能说“已经证明稳定有效”或“达到统计显著”。2026-09-07之前均为回顾性结果，真正前瞻OOS只能在参数冻结后顺序累计。
