# 答辩要点与教师咨询

## 三句话介绍

1. 银行每天需要阅读大量政策信息，但文本难以稳定进入量化研究和模型审计。
2. AlphaLens 用大语言模型理解语义，用固定谓词和经济规则约束，用时间滚动模型验证，形成从原文到概率的完整证据链。
3. 系统当前已打通真实数据 MVP，并明确区分“流程可用”和“预测增量已证实”。

## 项目亮点

- 选择与银行利率债定价、久期和流动性管理直接相关的业务场景。
- 大模型只做受约束的语义抽取，不直接给交易结论。
- 每个因素都能回到原文证据、来源链接和处理时点。
- 四条模型路线使用同一时间切分，用于初步检验文本是否存在增量；当前回顾性时间留出尚未建立正向增量，真正前瞻 OOS 仍需从规则冻结后累计。
- 数据不足时主动降级，不制造虚假预测成绩。

## 需要朱越腾老师判断的问题

1. 10 年期国债收益率作为主目标、DR007 作为辅助变量是否符合银行实际工作？
2. 五个交易日窗口和 `±2bp` 震荡阈值是否合理，是否应使用波动率动态阈值？
3. 六类因素是否覆盖主要传导机制，是否需要单列汇率或期限溢价？
4. 规则更适合作为输入特征、先验约束还是结果解释？
5. 正式增量检验需要多长历史、哪些政策阶段和哪些统计检验？

## 希望老师给出的可执行结论

- 主目标、窗口和阈值的建议值。
- 因素删改清单和各因素经济方向。
- 一个最聚焦的银行部门与使用时点。
- 正式回测范围、基准模型和最低验收标准。

本报告仅供研究参考，不构成投资建议
