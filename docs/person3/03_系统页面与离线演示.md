# 人员三：系统页面、工作模式与演示

## 五个页面

1. **每日投研总览**：数据截至日、10年期收益率、FDR007代理、上/下行/震荡概率、因子和规则摘要。
2. **政策文本分析**：粘贴文本或上传 TXT、Markdown、可检索 PDF，选择来源和发布时间，展示加入前后概率和完整证据链。
3. **因子与预测详情**：六类因子方向、模型贡献、冻结规则版本、训练窗口和债券价格方向解释。
4. **证据审计与人工审核**：原文、来源 URL、正文哈希、生效交易日、事件、谓词、规则、LLM 覆盖度；复核记录只追加不覆盖。
5. **历史回测与模型评估**：四条路线、准确率/Precision/Recall/F1/AUC/Brier、分期指标、校准、最近预测和典型案例。

## 后台自动投研

```bash
.venv/bin/python scripts/run_daily_rates_research.py --annotate-llm
```

该命令按顺序刷新官方市场数据、官方政策文本、结构化宏观数据、可恢复 LLM 注释和全部研究产物；服务器无法访问外部来源时可使用 `--skip-market --skip-text --skip-structured` 重建当前样本。每次运行状态追加到被 gitignore 的 `data/runtime/rates_daily_runs.jsonl`。

## 用户补充分析

上传文件只用于本次分析，不写入政策样本。PDF 使用 `pypdf` 提取文字；扫描版 PDF 没有文字层时会明确提示需要 OCR。分析接口不会保存页面中的 API Key，LLM 结果必须逐字证据校验，失败时显示确定性降级。

## 固定离线案例

`data/sample/rates_demo_cases.json` 包含：

- 公开市场逆回购和流动性投放；
- 增长与通胀同步回升；
- 政府债集中发行与资金面偏紧。

演示时从页面“固定演示案例”选择，不依赖临时联网。报告导出接口为 `GET /api/rates/report`。

## 启动

```bash
.venv/bin/pip install -r requirements.txt
.venv/bin/python 启动演示.py
```

反向代理部署时保持 `app/index.html` 的相对 `assets/`、`vendor/` 和 `api/` 路径，避免子路径部署时静态资源失效。
