# 人员三：因子、模型与实验验收

## 因子生成

文本经过去重、交易日映射、LLM/确定性双路抽取后，必须经过原文证据门控，再聚合为六类因子：货币政策、市场流动性、经济增长、通胀、债券供给、风险偏好。所有分数统一为收益率压力口径：正值表示10年期国债收益率上行压力，负值表示下行压力。

LLM 不是自由规则生成器。它只在固定 14 个谓词集合内判断，输出事件主体、动作、对象、方向、强度、期限、传导渠道和逐字证据。字段别名、缺少谓词、证据不在原文、与确定性结果冲突时分别记录并降级或标记 `disputed`。

## 四条模型路线

1. `market_baseline`：仅收益率和 FDR007 的滞后、变化、波动特征。
2. `text_only`：仅六类文本因子。
3. `fusion`：市场特征加六类文本因子。
4. `fusion_rules`：市场特征、文本因子和冻结规则压力。

模型是低自由度线性概率分类器，类别为收益率上行、震荡、下行；震荡阈值为未来 5 个交易日收益率变化绝对值不超过 2bp。

## 时间切分和防未来函数

- 发现期：2018-2022。
- 验证期：2023-2024。
- 冻结 OOS：2025-01 至最新。
- 每个预测日使用最多 756 个历史交易日，至少 252 个训练观测。
- 训练样本 `i` 必须满足 `i + 5 <= 预测日索引`，避免训练标签跨入预测日之后。
- 不随机打乱，不使用当前未发布的目标值。

## 当前样本结果

当前重新生成的冻结结果在 `data/sample/rates_backtest.json`：

| 路线 | 总观测 | 总准确率 | 总 Macro-F1 | OOS准确率 | OOS Macro-F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 仅市场数据 | 1899 | 38.39% | 0.3452 | 48.77% | 0.3343 |
| 仅文本因子 | 1899 | 39.55% | 0.3487 | 52.45% | 0.2863 |
| 市场+文本融合 | 1899 | 37.97% | 0.3372 | 49.26% | 0.3434 |
| 市场+文本+规则增强 | 1899 | 38.02% | 0.3379 | 49.51% | 0.3475 |

规则增强相对市场基线的 OOS 准确率差为 +0.735 个百分点，20 日移动区块 Bootstrap 95% 区间为 [-3.677, 5.392] 个百分点，区间覆盖零。因此当前结论是：**冻结 OOS 文本预测增量尚未建立**。这不是失败兜底，而是本版验收标准要求的诚实输出。

## 验收指标

系统输出 Accuracy、Macro Precision、Macro Recall、Macro-F1、每类 Precision/Recall/F1、one-vs-rest AUC、Brier、混淆矩阵、分时期结果、置信度校准和典型正确/错误案例。正式材料不能只展示单一准确率。
