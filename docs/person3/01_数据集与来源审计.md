# 人员三：数据集与来源审计

## 当前可运行样本

本次冻结样本由官方页面抓取后生成，更新时间以 `data/sample/rates_source_audit.json` 和 `rates_policy_source_audit.json` 为准：

| 数据 | 当前范围 | 数量 | 用途 |
| --- | --- | ---: | --- |
| 中债10年期国债收益率 | 2018-01-02 至 2026-09-01 | 2161个交易日 | 主预测目标和市场特征 |
| FDR007定盘利率 | 同上 | 2161个交易日 | DR007流动性代理和市场特征 |
| 人民银行公开市场/货币政策文本 | 2020-01-02 至 2026-08-31 | 374篇去重文本 | 事件、谓词、六类文本因子 |
| LLM结构化缓存 | 与政策文本按 `doc_id + source_sha256` 对齐 | 374条 | 可恢复的语义抽取和证据审计 |

市场样本每年从中债年度标准期限文件和中国货币网历史定盘接口下载；每个原始响应保存 SHA-256。文本样本记录官方正文 URL、发布时间、正文 SHA-256 和文档指纹。

## 来源边界

- 中债收益率曲线是10年期收益率的官方来源。
- 中国货币网历史 FDR007 定盘值只作为银行间流动性代理，不改名为原始 DR007 成交加权利率。
- 人民银行文本按官方列表页发现、正文抓取和发布日期解析处理。
- 财政部国债发行公告抓取器已实现为可选来源。财政部站点存在 502/限流时，流水线记录失败，不把标题或摘要伪装成正文，也不覆盖已成功的央行样本。
- 国家统计局 CPI/PPI/PMI、人民银行社融、MLF 操作表和财政部完整发行序列尚未进入当前 `rates_market.csv` 合同；它们只能作为后续结构化确认变量，不能在当前实验中声称已使用。

## 清洗与时间对齐

1. 市场数据要求交易日唯一、收益率和流动性为百分数数值、源 URL 有效、响应哈希为 SHA-256。
2. 文本按标题和正文去除空白后计算指纹；相同正文不重复贡献。
3. 文本发布时间早于或等于 17:30 的交易日映射到当日，否则映射到下一交易日；周末映射到下一交易日。
4. 文本只影响生效日起连续 5 个交易日，权重按 2 个交易日半衰期衰减。
5. 未来五日标签使用交易日序列第 `i+5` 行，最后 5 个交易日不产生标签。

## LLM 审计

历史缓存由 `scripts/annotate_rates_policy_texts.py` 生成，可中断后续跑。当前 374 条中 339 条通过固定 14 谓词、字段和原文证据门控，35 条明确回退确定性抽取。缓存不保存 API Key，只保存模型名、请求 ID、用量和结构化输出。
