市场样本每年从中债年度标准期限文件和中国货币网历史定盘接口下载；每个原始响应保存 SHA-256。文本样本记录官方正文 URL、发布时间、正文 SHA-256 和文档指纹。

2015—2019年共329篇文本，分年为60、71、70、66、62篇。总语料来源构成为：中国人民银行639篇、国家统计局92篇、财政部10篇。

## 来源边界

- 中债收益率曲线是10年期收益率的官方来源。
- 中国货币网历史 FDR007 定盘值只作为银行间流动性代理，不改名为原始 DR007 成交加权利率。
- 人民银行文本按官方列表页发现、正文抓取和发布日期解析处理。
- 国家统计局历史发布正文复用已核验语料并记录持久化正文哈希；财政部官方正文单独抓取并记录响应哈希。
- CPI/PPI/PMI公开数据接口、商务部数据中心的人民银行社融统计口径、央行逐月MLF公告、人民银行AFRE官方PDF和巨潮公开政府债发行表进入独立的 `rates_structured_data.csv`，不修改 `rates_market.csv` 字段。
- CPI/PPI/PMI当前由公开数据中心镜像下载，审计文件保留接口与响应哈希；正式生产部署应优先替换为国家统计局可稳定直连的原始文件。MLF逐月公告来自人民银行官网，正文响应保留SHA-256；MLF统一中标利率只接收正文可明确识别的一年期或统一利率。
- 政府债只使用公告时已知的计划发行量，不使用招标后实际发行量；同一债券跨交易市场代码按债券名称去重。AFRE政府债券余额历史列来自人民银行2025-11-05官方PDF，统计期为2017-01至2019-12，但按PDF公开时间作为可用时间，不回填到早期回测。

## 清洗与时间对齐

1. 市场数据要求交易日唯一、收益率和流动性为百分数数值、源 URL 有效、响应哈希为 SHA-256。
2. 文本按标题和正文去除空白后计算指纹；相同正文不重复贡献。
3. 文本发布时间早于或等于 17:30 的交易日映射到当日，否则映射到下一交易日；周末映射到下一交易日。
4. 文本只影响生效日起连续 5 个交易日，权重按 2 个交易日半衰期衰减。
5. 结构化值只能在 `release_time` 对齐后的交易日进入特征；统计期本身不代表当时已经公开。
6. 相同主体、动作、对象、方向、渠道和证据语义生成同一个独立事件键；重复公告不重复增加样本量。
7. 因子累计独立事件少于5个时标记 `insufficient_evidence`，因子值和依赖该因子的规则均不进入模型。
8. 未来五日标签使用交易日序列第 `i+5` 行，评估起点每5个交易日取一个，形成非重叠窗口；训练端另设5日embargo。

## LLM 审计

历史缓存由 `scripts/annotate_rates_policy_texts.py` 生成，可中断后续跑。与当前文本哈希匹配的404条中，363条通过固定14谓词、字段和原文证据门控，41条明确回退确定性抽取；新增国家统计局正文透明使用确定性路径，当前LLM可用覆盖率48.99%。缓存不保存 API Key，只保存模型名、请求 ID、用量和结构化输出。
