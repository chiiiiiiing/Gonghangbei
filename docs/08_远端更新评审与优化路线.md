# 远端更新评审与优化路线

## 结论

远端更新已经把项目从“流程样例”推进到“可运行的跨年度研究 MVP”：真实市场样本、人民银行文本、LLM 缓存、四路线滚动回测和五页研究工作台均已打通。当前最大问题不再是页面或链路是否存在，而是文本来源单一、六类因素覆盖失衡，以及 OOS 增量尚未达到统计稳定。

## 实验数据完成情况

- 10 年期国债收益率与 FDR007 代理：2018-01-02 至 2026-09-01，共 2161 个交易日。
- 人民银行政策文本：2020-01-02 至 2026-08-31，共 374 篇去重文本。
- LLM 结构化缓存：374 条；339 条使用模型结果，35 条透明降级。
- 日频因素：货币政策 85 个非零日、流动性 1433 个、增长 35 个、通胀 25 个、债券供给 0 个、风险偏好 40 个。
- 四条模型路线：各 1899 个滚动预测观测；2025 年以后冻结 OOS 各 408 个。
- 规则增强相对市场基线的 OOS 准确率差为 +0.735 个百分点，20 日移动区块 Bootstrap 95% 区间为 [-3.677, 5.392] 个百分点，不能确认稳定增量。

这说明人员三已经完成数据抓取、来源哈希、去重、时间映射、LLM 缓存、因素生成、模型比较和评估产物；尚未完成的是六类因素的均衡覆盖与正式增量验证。

## 前端比较与选择

选择远端更新版作为主视觉：冷白背景、深海军蓝顶栏、青绿色表示收益率下行压力、克制红表示上行压力、浅黄色表示研究不确定性。该方案比旧版大面积深色渐变更适合银行投研工作台，五个页面的数据密度和语义一致性也更好。

旧版深蓝渐变只保留在首页“未来五日收益率”核心卡片中，用于建立视觉主次，不扩展为整页背景。表格正文略增大，保证投屏阅读。

## 下一步优化顺序

1. **补数据覆盖**：优先接入财政部国债发行公告与发行量，消除债券供给因素全零；再补 CPI/PPI/PMI、社融、MLF 和经授权 DR007。
2. **做人工标注验收**：先复核 35 条降级样本，再对 339 条模型样本按年份、来源类型和谓词分层抽样，报告谓词级 Precision/Recall/F1 和证据命中率。
3. **控制文本失衡**：公开市场操作文本频率高，不能让“公告数量”替代政策强度；加入同日事件聚合、来源类型权重和重复模板识别的消融实验。
4. **做稳健性矩阵**：比较 1/5/10 日窗口、±1/±2/±3bp 阈值、固定阈值与波动率阈值；参数只在发现期和验证期选择，2025 年后 OOS 保持冻结。
5. **优化模型与基线**：增加多数类、随机游走、收益率动量等朴素基线；在低容量模型之外比较带类别权重的逻辑回归和树模型，但保持统一时间切分。
6. **完善页面表达**：首页同时展示“预测概率”和“结论可信度”；回测页突出 OOS 与置信区间；证据页增加来源类型、降级原因和因素覆盖筛选；默认隐藏开发字段。
7. **形成答辩证据**：所有 PPT 数字从冻结 JSON 自动生成，明确 FDR007 是代理、增量尚未建立、单文本只表示边际影响。

本报告仅供研究参考，不构成投资建议或自动交易指令。
