# 远端更新评审与优化路线

## 结论

远端更新已经把项目推进到可运行、可追溯的跨年度研究 MVP：真实市场样本、三部门政策文本、九类结构化指标、LLM 缓存、四路线非重叠滚动评估和五页研究工作台均已打通。当前最大限制是文本类别仍不均衡、人工抽取验收尚未完成，且回顾性时间留出没有建立正向预测增量。

## 实验数据完成情况

- 10 年期国债收益率与 FDR007 代理：2018-01-02 至 2026-09-01，共 2161 个交易日。
- 政策文本：2015-01-22 至 2026-08-31，共 741 篇；人民银行 639、国家统计局 92、财政部 10。
- 结构化数据：4669 条；MLF 操作量、MLF 利率、政府债计划发行 3 项可入模，缺少历史 vintage 的另外 6 项为 `audit_only`。
- LLM 结构化缓存：当前语料匹配 404 条，363 条通过门控，其余文本透明使用确定性路径。
- 模型期内独立事件：货币政策 17、流动性 302、增长 9、通胀 5、债券供给 0、风险偏好 10；债券供给标记为 `insufficient_evidence`，不进入模型。
- 四条模型路线：各 380 个非重叠五日预测观测，其中 2025 年至最新的回顾性时间留出各 81 个。
- 规则增强相对市场基线的时间留出准确率差为 `-13.58` 个百分点，20 个交易日移动区块 Bootstrap 95% 区间为 `[-22.22%, -7.41%]`。

这说明人员三已经完成数据抓取、来源哈希、去重、时间映射、LLM 缓存、因素生成、模型比较和评估产物。2015—2017 年早于市场样本起点的 201 篇文本仅保留审计，不再集中回放到 2018 年；当前实验明确不支持正向预测增量。

## 前端比较与选择

选择远端更新版作为主视觉：冷白背景、深海军蓝顶栏、青绿色表示收益率下行压力、克制红表示上行压力、浅黄色表示研究不确定性。该方案比旧版大面积深色渐变更适合银行投研工作台，五个页面的数据密度和语义一致性也更好。

旧版深蓝渐变只保留在首页“未来五日收益率”核心卡片中，用于建立视觉主次，不扩展为整页背景。表格正文略增大，保证投屏阅读。

## 下一步优化顺序

1. **补数据覆盖**：公开数据接入已完成；后续优先获得经授权的原始 DR001/DR007 历史序列，并扩大国家统计局和财政部独立政策事件覆盖。
2. **做人工标注验收**：对降级与通过模型门控的样本按年份、来源类型和谓词分层抽样，报告谓词级 Precision/Recall/F1 和证据命中率。
3. **控制文本失衡**：公开市场操作文本频率高，不能让“公告数量”替代政策强度；加入同日事件聚合、来源类型权重和重复模板识别的消融实验。
4. **做稳健性矩阵**：可补充参数敏感性的事后审计，但 2025 年后数据不得重新包装为前瞻 OOS；真正 OOS 从 2026-09-03 起累计。
5. **优化模型与基线**：增加多数类、随机游走、收益率动量等朴素基线；在低容量模型之外比较带类别权重的逻辑回归和树模型，但保持统一时间切分。
6. **完善页面表达**：首页同时展示“预测概率”和“结论可信度”；回测页突出时间留出与置信区间；证据页增加来源类型、降级原因和因素覆盖筛选；默认隐藏开发字段。
7. **形成答辩证据**：所有 PPT 数字从版本化 JSON 自动生成，明确 FDR007 是代理、当前仅为回顾性时间留出、增量尚未建立、单文本只表示边际影响。

本报告仅供研究参考，不构成投资建议或自动交易指令。
