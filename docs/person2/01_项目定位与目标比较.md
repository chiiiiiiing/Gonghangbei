# AlphaLens 国债利率版：项目定位与目标比较

## 一句话定位

AlphaLens利用大模型将央行及宏观政策文本转化为可量化、可验证、可追溯的金融因子，融合债券与银行间市场数据，辅助银行研判未来5个交易日的利率债市场方向。

## 面向谁、解决什么问题

主要用户是银行金融市场部的债券研究、交易支持、资产负债管理和市场风险人员。系统解决的不是“让大模型直接下单”，而是把分散、难以量化的政策信息转成可审计的研究信号，并检验这些信号能否在传统市场指标之外提供增量信息。

## 10年期国债收益率与DR007目标比较

| 比较维度 | 10年期国债收益率 | DR007 |
| --- | --- | --- |
| 在本项目中的角色 | 主预测目标 | 流动性输入与辅助状态 |
| 银行业务含义 | 利率债定价、久期风险和债券组合损益 | 银行间资金价格和短端流动性松紧 |
| 预测口径 | 未来5个交易日上涨、震荡或下降 | 当前偏松、中性或偏紧，并作为解释变量 |
| 与政策文本的关系 | 汇总增长、通胀、供给和风险偏好的中长端定价结果 | 更直接反映央行公开市场操作和资金供求 |
| 可解释性 | 能形成“因素—规则—方向”的完整投研结论 | 适合作为政策传导链的中间节点 |
| 首版数据方案 | 中债国债收益率曲线10年期 | 当前使用中国货币网DR007；历史MVP以FDR007定盘利率做代理并明确标注 |
| 最终选择 | **主目标** | **辅助变量，不单独作为最终预测目标** |

## 标签与输出

- 未来第5个交易日相对当日变化大于 `+2bp`：收益率上行。
- 小于 `-2bp`：收益率下行。
- 其余：收益率震荡。
- 2bp阈值为可配置研究参数，需要向朱越腾老师确认其经济含义与稳健性。

系统同时给出与收益率方向相反的债券价格解释，例如“收益率下行—债券价格偏强”，避免非专业用户误读。
