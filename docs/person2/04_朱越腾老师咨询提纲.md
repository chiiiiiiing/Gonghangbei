# 朱越腾老师咨询提纲

## 开场说明（1分钟）

我们把原有的“产业文本增强碳酸锂期货量化”迁移为面向银行金融市场的利率债投研平台。主目标是未来5个交易日10年期国债收益率方向，DR007用于描述流动性状态；大模型负责把政策文本转化为有原文证据的宏观因子，传统量化模型负责预测和回测。

## 希望老师重点判断的五个问题

1. **场景与目标**：将银行金融市场部、资产负债管理和市场风险作为用户是否聚焦？10年期国债收益率是否比DR007更适合作为主预测目标？
2. **预测口径**：五个交易日是否符合银行利率债投研节奏？以正负2bp划分“震荡”的默认设置是否合理，是否应按波动率动态调整？
3. **因素体系**：货币政策、流动性、增长、通胀、债券供给和风险偏好是否覆盖主要传导机制？是否需要单独加入汇率或期限溢价？
4. **方法融合**：固定谓词、经济规则和统计模型应如何分工？规则更适合作为特征、先验约束还是结果解释？
5. **增量证明**：除Macro-F1和概率校准外，应采用哪些检验来证明文本相对市场变量有稳健增量？需要多长历史和哪些市场阶段？

## 向老师展示的材料

- 一句话定位和目标比较表。
- 六类因素字典与五条规则。
- 技术流程图和五个页面原型。
- 四路线滚动回测，但明确单年度MVP结果不是正式结论。
- 一条政策文本的“加入前/加入后”概率变化和原文证据链。

## 需要老师给出的可执行结论

- 主目标、预测窗口和震荡阈值的建议值。
- 因素删改清单及每类因素的经济方向。
- 至少一个更符合银行业务的使用场景。
- 正式回测的时间范围、基准模型和验收指标。
