# 六类宏观文本因素字典与规则

所有因素分数都以“对10年期国债收益率的压力方向”为统一口径：正值表示收益率上行压力，负值表示收益率下行压力。

| 因素 | 固定谓词 | 对收益率的默认方向 | 典型证据 |
| --- | --- | --- | --- |
| 货币政策 | `policy_stance_eases` / `policy_stance_tightens` | 宽松向下、收紧向上 | 降准、降息、适度宽松、加息、收紧 |
| 市场流动性 | `liquidity_supply_increases` / `liquidity_supply_decreases` | 投放向下、回笼向上 | 逆回购净投放、资金面充裕、净回笼 |
| 经济增长 | `growth_outlook_strengthens` / `growth_outlook_weakens` | 增长增强向上、走弱向下 | PMI扩张、需求改善、经济下行 |
| 通胀 | `inflation_pressure_rises` / `inflation_pressure_falls` | 通胀上升向上、回落向下 | CPI/PPI回升或下降 |
| 债券供给 | `government_bond_supply_rises` / `government_bond_supply_falls` | 供给增加向上、减少向下 | 国债或地方债加快发行、缩量 |
| 风险偏好 | `risk_aversion_rises` / `risk_aversion_falls` | 避险上升向下、风险偏好回升向上 | 不确定性增加、风险缓解 |

## 规则层

1. 货币政策宽松且流动性投放增加：收益率下行压力增强。
2. 政策边际收紧：收益率上行压力增强。
3. 增长预期与通胀压力同步增强：收益率上行压力增强。
4. 政府债券供给增加：收益率上行压力增强。
5. 避险需求上升：利率债需求增加，收益率下行压力增强。

规则只有在谓词包含原文证据且未出现“确定性程序与大模型冲突”时才会触发。冲突结果保留在审计页面，但不进入量化分数。
