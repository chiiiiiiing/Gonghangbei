# 人工标注验收操作说明

## 当前状态

系统已从三个来源分层生成60篇盲审文档：中国人民银行30篇、国家统计局20篇、财政部10篇。每篇需判断14个固定谓词，共840个二值金标签。盲审文件不含模型结果；当前金标签为空，因此不宣称已完成人工验收。

## 文件

- `data/review/rates_annotation_blind_sample.csv`：复核员只阅读此文件中的原文、来源和发布时间。
- `data/review/rates_annotation_gold_template.csv`：填写 `human_value`、`human_evidence_text`、`reviewer`、`reviewed_at` 和 `notes`。
- `data/review/rates_annotation_validation.json`：机器可读验收结果。
- `data/review/rates_annotation_validation.md`：人可读验收摘要。

## 标注规则

1. `human_value` 只能填 `0` 或 `1`；`1` 表示原文明确支持该谓词。
2. 正标签必须复制原文中能直接支持判断的片段到 `human_evidence_text`；不用自己的改写或推测。
3. 不查看 `rates_evidence_audit.json` 或页面上的模型抽取结果，避免被模型判断影响。
4. 建议两名组员分别保存一份标注副本，对分歧项讨论并形成最终金标签；最终文件每个 `sample_id + predicate_name` 只保留一行。

## 执行命令

```bash
.venv/bin/python scripts/review_rates_annotations.py prepare
# 组员离线填写 data/review/rates_annotation_gold_template.csv
.venv/bin/python scripts/review_rates_annotations.py evaluate
```

只有当 `labels_completed` 等于840且 `status` 为 `complete` 时，才能引用谓词级 Precision/Recall/F1 和证据命中率。

本报告仅供研究参考，不构成投资建议。
