## 真正不建议删除的原因

- `查看材料/` 根目录里的很多文件被交付自检脚本登记。
- `因子研究报告.md` 由正式报告流程生成；Flask Demo 的在线研究记录使用同一批历史 CSV 口径。
- `数据格式规范.md` 和 `事件与谓词Schema.md` 是 B/C 契约，不能随意移动或改字段。
- 自动脚本会重写部分报告，如果物理移动，下一次复跑可能又生成到根目录。
