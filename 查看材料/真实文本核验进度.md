## 安全复跑命令

人工替换一批真实文本后，使用保留输入的安全模式重刷下游结果：

```bash
.venv/bin/python run_pipeline.py --preserve-inputs
```

如只想重算 B 线实体链接、事件和谓词，可运行：

```bash
.venv/bin/python run_b_pipeline.py --skip-sample-generation
```

不要在真实文本写入后使用 `--force-sample-generation`。
