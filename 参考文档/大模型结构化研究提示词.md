# AlphaLens 大模型结构化研究提示词

版本：`alphalens-research-v1.0`

本报告仅供研究参考，不构成投资建议

## 使用位置

运行时模板位于 `src/ai/prompts.py`。本文说明 Prompt 的职责、输入和输出约束，不替代代码中的 JSON Schema。

## 模型职责

大模型只负责提出研究候选：

1. 从输入文本中抽取一个主要金融事件。
2. 从给定的 30 只股票池中提出直接相关实体。
3. 判断锁定 Schema 中的 19 个谓词。
4. 参考 Embedding 检索到的相似冻结规则，提出最多 3 条新候选规则。

大模型不负责计算历史收益、规则评分、因子值或回测指标，也不得输出目标价、收益预测和买卖建议。

## 输入内容

- 标题、正文、来源类型、来源名称、首次公开日期和正文 URL。
- 锁定事件类型枚举。
- 19 个谓词名称和定义。
- 30 只股票的代码、名称和行业。
- Embedding 检索得到的最多 5 条相似冻结规则。

正文最多发送前 8000 个字符。API 密钥不会进入 Prompt。

## 结构化输出

```json
{
  "summary": "仅基于原文的研究摘要",
  "event": {
    "event_type": "policy_support",
    "subject": "事件主体",
    "object": "事件客体",
    "impact_path": "A→B→C",
    "evidence_text": "输入中的连续原文片段",
    "evidence_strength": 0.90
  },
  "related_stocks": [
    {
      "code": "300750",
      "name": "宁德时代",
      "confidence": 0.85,
      "rationale": "关联理由"
    }
  ],
  "predicates": [
    {
      "name": "has_policy_support",
      "value": "true",
      "confidence": 0.95,
      "rationale": "原文证据"
    }
  ],
  "candidate_rules": [
    {
      "name": "候选规则名称",
      "conditions": ["has_policy_support", "policy_directly_related_to_business"],
      "target_label": "policy_signal",
      "rationale": "等待历史样本检验的原因"
    }
  ]
}
```

## 程序校验

- `event_type` 必须属于锁定枚举。
- `evidence_text` 必须是标题或正文中的连续片段。
- 股票代码必须存在于股票池，名称由股票池覆盖；只有原文明确点名的 AI 实体才可作为计算链路回退。
- boolean 谓词只能是小写字符串 `true` 或 `false`。
- score 谓词必须位于 0 到 1。
- 候选规则只能包含已定义谓词，状态固定为 `pending_statistical_validation`。
- AI 候选不会直接写入 `events.csv`、`predicates.csv` 或 `rules.csv`。

## 最终口径

大模型负责语义理解与假设提出，确定性程序负责 Schema 校验、冻结规则执行、因子计算、收益对齐和回测。只有经过历史支持数、样本外稳定性和人工金融口径审核的规则，才能进入正式因子。
