# AlphaLens 参考文档索引

> 本报告仅供研究参考，不构成投资建议

`参考文档/` 存放底层契约、赛题背景和方法材料。日常使用请先看 `../完整说明文档.md`；需要确认字段、事件谓词口径或扩展 Prompt 时，再回到这里。

## 必读契约

| 文件 | 什么时候看 |
|------|------------|
| `数据格式规范.md` | 改 CSV、读 CSV、联调 B/C 字段前必须看 |
| `事件与谓词Schema.md` | 改事件类型、谓词定义、规则解释口径前必须看 |

## 项目背景

| 文件 | 什么时候看 |
|------|------------|
| `赛题与工作说明.md` | 需要回到赛题原文、交付要求和项目背景时 |
| `工作推进与分工文档.md` | 需要确认 A/B/C 分工、阶段安排和 Demo 叙事时 |
| `数据负责人工作指南.md` | B 角色维护数据、做抽检或交接时 |

## 数据和 Prompt 参考

| 文件 | 什么时候看 |
|------|------------|
| `数据来源清单.md` | 补真实文本来源或解释数据来源时 |
| `事件抽取提示词.txt` | 调整事件抽取 prompt 时 |
| `谓词判断提示词.txt` | 调整谓词判断 prompt 时 |
| `大模型结构化研究提示词.md` | 查看当前运行 Prompt、结构化 JSON 和程序校验边界时 |

## 方法论背景

| 文件 | 什么时候看 |
|------|------------|
| `RIFT规则归纳论文.pdf` | 需要解释“规则归纳”方法来源或准备答辩引用时 |

## 不要随便改的内容

- `数据格式规范.md` 中定义的 6 张核心 CSV 字段名是 B/C 契约，未经确认不要改。
- 项目对外口径不能写成预测股价或投资建议。
- 若新增谓词，优先追加 `predicate_name` 取值，不要破坏 `predicates.csv` 原字段结构。
