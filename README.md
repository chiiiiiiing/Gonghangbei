# AlphaLens 可运行演示成果

AlphaLens 将政策、公告、财经新闻和互动问答等非结构化金融文本转化为可解释、可回测、可复用的另类因子研究素材。

系统是量化研究助手，不预测股票价格，不提供投资建议。

本报告仅供研究参考，不构成投资建议

## 启动

需要 Python 3.10 或更高版本。在当前目录执行：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python 启动演示.py
```

浏览器打开 [http://127.0.0.1:8701](http://127.0.0.1:8701)。

## 使用

1. 进入“新文本分析”。
2. 输入来源类型、首次公开日期、来源名称、正文 URL 和金融文本。
3. 选择“模式一：大模型候选 + 规则校验”。
4. 在页面密码框临时填写 DeepSeek API Key。
5. 点击“开始分析”，查看实体、事件、谓词、规则和候选因子。
6. 切换“历史研究概览”，查看冻结规则、因子截面和历史回测。

模式一缺少 API Key、接口失败或模型输出不合法时会直接报错，不会降级生成候选因子。模式二为单独标注的纯规则复现模式。

API Key 仅随本次分析请求发送，不写入文件或浏览器存储。若接口报错，页面会区分 Key 无效、余额不足、模型权限不足和请求频率过高；模型偶发返回空内容时会自动重试一次。

## 已知限制

- 当前历史样本用于验证研究链路，不代表未来表现。
- 行情中的 `adj_factor=1` 是占位字段，不是真实复权因子序列。
- AI 候选规则必须经过程序校验、历史统计和人工金融口径审核。
- 新文本只生成当下候选因子，不会立即拥有未来收益。
- 历史 Rank IC 使用“交易日 + 股票”唯一横截面：事件信号先按股票汇总，未触发股票补零，行业内标准化后再与 5 日前向收益计算秩相关。
